# Model Evaluation Results

This repository contains the results of the model evaluation across different aspects. The evaluation was performed manually, so there may be small human errors. Any corrections will be reflected in future versions of the repository.

## Included Files

### 1. `outputs_evaluation.xlsx`
This file contains the **outputs generated by the model** along with their manual evaluation.

### 2. `ontology_metrics_quality_score.xlsx`
This file contains the **list of ontologies with their Quality Score**, sorted by score and considering accumulated tokens.

## Evaluation Guide
To ensure a structured assessment of the model's outputs, the following evaluation guide is used to identify different types of errors:

### Guide for Errors

| **Error Type** | **Definition** | **Examples** |
|--------------|-------------|-------------|
| **Syntactic errors** | Identify syntax violations in triples. Incorrect insertion of characters (e.g., opening a bracket at the end of a triple instead of starting a new triple). Missing delimiters (e.g., missing periods, semicolons, parentheses, or brackets). | `:subj1 :rel1 :obj1,`<br> `:subj2 :rel2 :obj2`<br><br> `subj3.`<br><br> `subj4 [ :rel4 :obj4` |
| **Triplet repetition** | Detects duplication of entities with identical subjects, properties, and relationships. | `:subj1 :rel1 :obj1.`<br> `:subj1 :rel1 :obj1.` |
| **Text repetition** | Detects repeated comments that do not provide any useful information. | `#This is subj1`<br> `#This is subj1` |
| | Detects repeated text in literals that do not provide any useful information. | `:subj :rel "This is sth. This is sth. This is sth."` |
| **Semantic redundancy** | Identifies relationships that convey the same meaning but use different properties. | `:subj :hasSynonym "sth".`<br> `:subj :synonym "sth".` |
| **Ambiguity** | Detects entities with identical properties and relationships, but different subjects, making it unclear whether they represent the same concept or distinct entities that need further differentiation. | `:Person a owl:Class; rdfs:label "Person".`<br> `:Human a owl:Class; rdfs:label "Person".` |
| | Two different objects for the same relation. | `:subj :def "sth".`<br> `:subj :def "sth diff".` |
| **Semantic contradictions** | Detects logical inconsistencies with respect to OWL semantics. This contradiction arises because an entity in OWL cannot be both a class and an object property simultaneously. | `:subj rdf:type owl:Class.`<br> `:subj rdf:type owl:ObjectProperty.` |
| | Use of an entity with an incorrect type in a position that requires a different kind, such as using an IRI instead of a literal, or vice versa. | `:subj rdfs:isDefinedBy "sth"` |
| **Vocabulary errors** | Improper use of predefined and immutable vocabulary: OWL, RDF, RDFS, and XSD. | `# Incorrect usage:`<br>`owl:Property`<br>`# Correct usage:`<br>`owl:ObjectProperty` |

## Important Notes
- The evaluation was conducted manually, so there may be minor human errors in the results.
- If any errors are found, they will be corrected in future versions of the repository.
