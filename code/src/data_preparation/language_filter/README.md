# Language Filtering in Ontologies

## Overview
The scripts in this directory are designed to analyze and filter ontologies based on their language content. Since our focus is on generating ontologies with English literals, these scripts help identify language distributions, detect ontologies without English content, and provide insights into linguistic diversity within the dataset.

The process consists of three steps:
1. **Language Identification:** Detects the percentage of different languages present in each ontology.
2. **Ontology Selection by Language:** Identifies ontologies that do not contain English literals.
3. **Language Distribution Analysis:** Computes the overall language distribution across all ontologies.

## Scripts

### 1. `identify_language.py`
This script analyzes a set of ontologies stored in a given folder and generates an Excel file containing the percentage of each detected language per ontology. It uses the `langdetect` library to determine the language of literals within each ontology.

#### **Input:**
- A folder containing ontology files in Turtle (`.ttl`) format.

#### **Output:**
- An Excel file (`ontology_metrics_lang.xlsx`) with:
  - File name of each ontology.
  - A dictionary indicating the percentage of literals detected in each language.

This generated Excel file serves as the input for the other scripts.

#### **Computational Requirements:**
For large datasets, the execution of this script requires significant computational resources. In our case, when processing the DBpedia dataset (3.22 GB in Turtle format), local execution was not feasible due to memory and processing constraints. Instead, we used a high-performance computing environment with **64 CPU cores**, and the processing took several hours to complete. Users working with similarly large datasets should ensure they have access to adequate computing power.

---

### 2. `select_ontologies_by_language.py`
This script processes `ontology_metrics_lang.xlsx` to identify ontologies that do not contain English literals.

#### **Functionality:**
- Extracts the language distribution of each ontology.
- Identifies ontologies where English (`"en"`) is absent.
- Outputs a list of ontology file names that do not contain English literals.

#### **Output:**
- A text file (`files_without_english.txt`) containing the names of ontologies without English literals.
- A printed list of such ontologies.

**Important note:** Some ontologies in the output list may not contain any textual literals at all. These ontologies might consist only of IRIs (Internationalized Resource Identifiers), which are still valid for semantic data training. Currently, reviewing these cases is a manual process.

**DBpedia Filtering (July 15, 2024)**
In the DBpedia dataset downloaded on July 15, 2024, ontologies were removed if they neither contained English literals nor were exclusively composed of IRIs. The following ontologies were excluded based on this criterion:
- `bgt--def_type=parsed.ttl`
- `def--nen3610_type=parsed.ttl`
- `datosabiertos--kos--sector-publico--empleo--grupo-profesional_type=parsed.ttl`

These ontologies were manually removed from the `ontology_metrics_lang.xlsx` file and the `full_dataset` folder to ensure they are not processed furthe to proceed with the analysis of the remaining ontologies. This ensures that non-English ontologies that lack meaningful textual content are not included in the training dataset.

---

### 3. `language_frequencies.py`
This script analyzes the overall language distribution in the dataset based on the Excel file generated by `identify_language.py`.

#### **Functionality:**
- Reads `ontology_metrics_lang.xlsx`.
- Aggregates language data across all ontologies.
- Computes the percentage of each language in the dataset.
- Stores a sorted list of languages and their frequencies in a text file (`language_frequencies.txt`).

This script provides insights into the linguistic composition of the dataset and helps assess the balance between different languages.

## Summary
These scripts collectively support the filtering and analysis of ontologies based on language. The workflow is as follows:
1. Use `identify_language.py` to generate language statistics.
2. Use `select_ontologies_by_language.py` to filter out ontologies without English literals.
3. Use `language_distribution.py` to analyze overall language representation.

This structured approach ensures that English remains the dominant language in the dataset while preserving semantic diversity.
