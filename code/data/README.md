# Data Directory

This folder contains datasets and resources related to ontology processing. It is structured as follows:

## Folder Structure

- **sample/** → Contains sample ontologies for testing and development.
- **ontology_repository/** →  This folder is intended to store the complete set of ontologies to be processed. These ontologies will be used for analysis, evaluation, and generation tasks within the framework

## Description

The **sample** folder currently includes **three example ontologies** that can be used for testing ontology-based tasks. These ontologies serve as a reference for processing and evaluation within the framework.

The **ontology_repository** folder is planned to store a broader collection of ontologies sourced from various domains. This repository can be expanded as needed to support additional experiments and evaluations.

---

## Usage

To use the sample ontologies in the `sample/` folder, simply point your scripts to the relevant ontology files. The framework is designed to process and analyze these ontologies to compute relevant metrics.

If additional ontologies are added, ensure they follow the expected format for seamless integration.
